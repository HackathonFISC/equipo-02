## Changes

- Added `PROFILE_CREDENTIAL_STATUSES` (`declared`, `verified`, `partially_verified`, `unverified`, `rejected`) and the `ProfileCredentialStatus` type to `apps/agent-runtime/src/application/evidence.ts`.
- Added `ProfileEvidenceItem` interface (`id`, `kind`, `text`, `credentialStatus`) to `evidence.ts`.
- Added `toApplicationEvidence(profileEvidence): EvidenceItem[]` to `evidence.ts`. Certification evidence keeps `verified` only when already verified; `declared`/`partially_verified`/`unverified`/`rejected` certifications map to `unverified`. Non-certification evidence (`experience`, `skill`, `education`) maps to `not_applicable` regardless of input status. `id`, `kind`, and `text` are preserved.
- Exported `toApplicationEvidence`, `EvidenceItem`, `CredentialStatus`, and `ProfileCredentialStatus` from `apps/agent-runtime/src/index.ts`.
- Added `apps/agent-runtime/src/application/__tests__/evidence.test.ts` with 5 tests covering the mapping rules, field preservation, and empty input.
